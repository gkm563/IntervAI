# Contributing to IntervAI

## Milestone-Driven Development
IntervAI is developed strictly following the milestones outlined in Section 131 of the PRD:
1. **Milestone 1**: Foundation (Repo, Docker, Postgres/Supabase, Auth Flow, Landing Page skeleton)
2. **Milestone 2**: Profile & Resume Pipeline
3. **Milestone 3**: Text-Mode Interview Engine
4. **Milestone 4**: Report & Learning Path
5. **Milestone 5**: Voice Mode (STT/TTS)
6. **Milestone 6**: 3D Avatar (Phase 1)
7. **Milestone 7**: Video & Observational Vision
8. **Milestone 8**: Memory, pgvector & Coaching
9. **Milestone 9**: SEO, i18n & Performance Polish
10. **Milestone 10**: Growth Features

## Git Commit Conventions
Follow Conventional Commits:
- `feat(auth): add email OTP verification endpoint`
- `fix(frontend): resolve password strength meter edge case`
- `docs(api): update authentication endpoints reference`
- `chore(infra): add docker-compose postgres service`
